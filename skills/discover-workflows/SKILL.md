# Workflow

1. Extract recurring goals, steps, constraints, tools, and failures from the chats.
2. Group duplicates; ignore one-offs and generic behavior.
3. Rank candidates by recurrence, value, stability, and skill fit.
4. Propose only strong candidates with a name, evidence, trigger, and minimal steps.

Do not create a skill unless asked.
