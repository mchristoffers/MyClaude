## Worktree workflow

Before making any change in a Git repository, explicitly load and follow the
installed Agent Skill named `worktree-workflow`.

This workflow is mandatory, including for small documentation or configuration
changes. If the skill is unavailable, do not modify the repository; report that
it must be installed first.
